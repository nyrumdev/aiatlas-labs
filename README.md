# AI 아틀라스 실습 키트 · AI Atlas lab kits

AI 아틀라스 앱의 실습에서 PC 로 그대로 쓰는 파일 묶음입니다. 키트는 누구나 무료로 받을 수 있습니다. 절차 설명은 앱의 실습 화면에 있고, 앱에서 실습은 앱 안 구매 '실습 패키지'로 열립니다.
